# Secure Algorithmic Trading Platform

A collaborative Python project focused on developing a secure algorithmic trading platform for market analysis, backtesting, and automated trading research.

This project combines trading system development with cybersecurity best practices to demonstrate secure software engineering principles in financial applications.

## Contributors
Michelle Law : Cybersecurity & Risk Controls
Michael Kennedy: Trading Strategy and Bot Development

Features: 
### Trading 
- Market data collection
- Trading strategy simulation
- Backtesting framework
- Risk management controls

### Cybersecurity
- Secure configuration using environment variables
- Input validation
- Trade-size limits
- Daily loss limits
- Allowed-symbol restrictions
- Emergency kill switch
- Audit logging
- Dependency vulnerability scanning
- Security-focused testing

## Project Structure

- `bot/` - trading bot logic
- `security/` - cybersecurity controls and monitoring
- `tests/` - automated tests
- `MIKESnotebooks/` - research and strategy development
- `config/` - configuration files
